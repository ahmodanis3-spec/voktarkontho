ভোক্তার কণ্ঠস্বর: আপডেট ফাইল

ফাইল:
1. index.html     : পুরো সাইট (এটি আপনার আগের index.html-এর জায়গায় বসান)
2. law-setup.sql  : আইন সম্পাদনার ডেটাবেস টেবিল (একবার চালাতে হবে)

ধাপ (একবারের কাজ):
1. Supabase খুলে SQL Editor-এ যান, law-setup.sql-এর পুরো লেখা পেস্ট করে Run করুন।
2. Supabase > Authentication > Providers > Email-এ "Allow new users to sign up" বন্ধ রাখুন,
   যাতে আপনার অ্যাডমিন অ্যাকাউন্ট ছাড়া কেউ সম্পাদনা করতে না পারে।
3. index.html আপনার হোস্টিংয়ে আপলোড করুন।

ব্যবহার:
1. সাইটে অ্যাডমিন হিসেবে লগইন করুন (আগের মতোই)।
2. "ভোক্তা অধিকার ও আইন" খুলুন। লগইন থাকলে নতুন বাটন দেখা যাবে:
   - "＋ নতুন বিভাগ যোগ করুন": নতুন বিভাগ বানান
   - বিভাগের ভেতরে "＋ নতুন আইন/ধারা যোগ করুন"
   - প্রতিটির নিচে ✏️ সম্পাদনা, ↑ ↓ ক্রম বদল, 🗑 মুছুন
3. "সংরক্ষণ করুন" চাপলে সবার জন্য সাইটে আপডেট হয়ে যায়।

বিস্তারিত লেখার নিয়ম:
- প্রতিটি লাইনে একটি কথা লিখুন
- "- " দিয়ে শুরু করলে তালিকা, "! " দিয়ে শুরু করলে হলুদ সতর্কবার্তা, "## " দিয়ে উপশিরোনাম
- **শব্দ** লিখলে মোটা হবে
- 📞 16121 লিখলে ফোন করার লিংক হবে

সাধারণ ব্যবহারকারী শুধু দেখতে পাবেন, কোনো সম্পাদনার বাটন দেখবেন না।
