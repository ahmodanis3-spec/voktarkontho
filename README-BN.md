# ভোক্তার কণ্ঠ — Brand & UI Asset Pack

বাংলাদেশের নাগরিকদের অভিযোগ জানানোর প্ল্যাটফর্মের জন্য লোগো, অ্যাপ আইকন, নাগরিক-থিমের ছবি, আইকন এবং CSS থিম।

## ফোল্ডার
- `assets/logo/` — ব্র্যান্ড ব্যানার, অ্যাপ আইকন, SVG লোগো
- `assets/icons/` — অভিযোগ, স্ট্যাটাস, প্রোফাইল, নিরাপত্তা, সাপোর্ট, রিপোর্ট, সেটিংস, আইন, সাহায্য
- `assets/illustrations/` — নাগরিক হিরো ও ফুটার ব্যানার
- `assets/backgrounds/` — স্মৃতিসৌধ, ঢাকা, কেনাকাটা, বিচার ও ভোক্তা সুরক্ষা
- `css/` — সবুজ-লাল-নীল রঙের CSS থিম

## ব্যবহার
1. ZIP extract করে ফাইলগুলো আপনার GitHub প্রজেক্টে কপি করুন।
2. HTML-এর `<head>` অংশে যোগ করুন: `<link rel="stylesheet" href="css/voktar-kontho-theme.css">`
3. SVG লোগো: `assets/logo/voktar-kontho-logo.svg`
4. App icon: `assets/logo/app-icon.webp`
5. আইকন ব্যবহার করতে উদাহরণ: `<img src="assets/icons/complaint.webp" alt="অভিযোগ">`

নোট: এগুলো ভিজ্যুয়াল/ব্র্যান্ডিং অ্যাসেট। অভিযোগ জমা, যাচাই, লগইন বা প্রশাসনিক কার্যকারিতার কোড এতে অন্তর্ভুক্ত নয়।
